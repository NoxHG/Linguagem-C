# 🖥️ Linguagem C

Repositório criado para **estudo e aprendizado da linguagem de programação C**.
Aqui estão minhas aulas, exercícios, testes e projetos desenvolvidos durante o processo de aprendizado.

> 📚 **Objetivo:** aprender C desde os fundamentos até conceitos mais avançados de programação de sistemas.

Sinta-se à vontade para explorar os arquivos, estudar os códigos e utilizar o conteúdo como referência.

---

## 🛠️ Ferramentas

Ferramentas utilizadas no desenvolvimento:

* **Visual Studio Code** — Editor de código
* **Git** — Controle de versão
* **GitHub** — Hospedagem e gerenciamento do repositório
* **MSYS2** — Ambiente Unix-like para Windows
* **MSYS2 UCRT64** — Ambiente utilizado para compilação
* **GCC** — Compilador C

## ⚙️ Compilação

Os programas podem ser compilados utilizando o **GCC** através do MSYS2 UCRT64.

```bash
gcc programa.c -o programa.exe
```

Para executar:

```bash
./programa.exe
```
